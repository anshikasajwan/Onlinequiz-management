# Online quiz management System

A web-based **Online Quiz Management System** designed to simplify quiz creation, management, and evaluation. The platform provides an efficient way for administrators to create quizzes while enabling users to attempt tests and receive instant results.

## 📌 Overview

The Online Quiz Management System is a full-stack web application that automates the quiz process, reducing manual effort in conducting assessments. It offers a secure and user-friendly interface for managing quizzes, users, and results.

## ✨ Features

- 🔐 User Authentication (Admin & User Login)
- 📝 Create, Update, and Delete Quizzes
- 📚 Manage Questions and Categories
- ⏱️ Attempt Quizzes Online
- 📊 Automatic Score Calculation
- 📈 Instant Result Generation
- 💾 Secure Database Management
- 📱 Simple and Responsive User Interface

## 🚀 Getting Started

### Prerequisites

- XAMPP
- PHP 7+
- MySQL
- Web Browser

### Installation

1. Clone the repository

```bash
git clone https://github.com/anshikasajwan/Onlinequiz-management.git
```

2. Move the project folder to the **htdocs** directory.

3. Start **Apache** and **MySQL** using XAMPP.

4. Import the database into phpMyAdmin.

5. Open your browser and visit:

```
http://localhost/Onlinequiz-management/
```
